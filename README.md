# MotoTrack

Aplicación [Expo](https://expo.dev) para gestionar motocicletas: registro, gastos, servicios e insights.

## Primeros pasos

1. Instalar dependencias

   ```bash
   npm install
   ```

2. Iniciar la app

   ```bash
   npx expo start
   ```

En la salida del terminal verás opciones para abrir la app en:

- [Development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Emulador de Android](https://docs.expo.dev/workflow/android-studio-emulator/)
- [Simulador de iOS](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), un entorno limitado para probar el desarrollo con Expo

Puedes empezar a desarrollar editando los archivos dentro de **`src/app`**. Este proyecto usa [enrutamiento basado en archivos](https://docs.expo.dev/router/introduction) con Expo Router.
